# Exactspace UI Developer Internship Assignments

This repository contains two ReactJS projects submitted for the UI Developer Internship at Exactspace Technologies.

## 1. Chat App
A React application simulating a chat interface.
- Includes a message thread and text input.
- Assigns a random username to the sender.
- Includes a "Like" button feature for messages.

## 2. Photo Gallery
An infinite-scrolling photo gallery.
- Fetches images using the `https://picsum.photos/v2/list` API.
- Displays the author's name for each photo.
- Includes a "Like" button feature for photos.

## How to Run Locally
1. Clone this repository.
2. Open either the `chat-app` or `photo-gallery` folder in your terminal.
3. Run `npm install` to download dependencies.
4. Run `npm run dev` (or `npm start`) to start the development server.
